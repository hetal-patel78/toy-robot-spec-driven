## Output channels at a glance
| What the app prints | When | Channel |
|---|---|---|
| `Output:` + `X,Y,F` (e.g. `0,1,NORTH`) | Every REPORT | Standard output |
| Warnings | Bad line, blocked MOVE, off-table PLACE, command before PLACE | Standard error |
| Echo `> command` | File runs only | Standard error |
| `> ` prompt | Typing only | Standard error |
| Usage hint | When a file-name argument is passed | Standard error |

## Assumptions
- **A1:** The output may be checked automatically against expected text, or read by a person; the challenge does not say. (Affects the `Output:` label.) Default: print `Output:` before the result, and document the format in the README.
- Other assumptions, stated in the README: 0..4 with (0,0) at SOUTH WEST; invalid or blocked commands ignored with a warning on standard error; case-insensitive, full direction words; AI prompts and artefacts will be included.
